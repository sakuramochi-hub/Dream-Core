# 放課後の8回目

ブラウザで動く、ギャルゲーム型の異変探しゲームひな型です。実行に必要な外部ライブラリはありません。Python 3 はローカルサーバーとシナリオエディタに使用します。

## 起動

ゲーム：`start.bat` をダブルクリック。Pythonサーバー起動後、ブラウザが開きます。終了はコマンドプロンプトで `Ctrl+C`。

シナリオエディタ：`start_editor.bat` をダブルクリック。ブラウザでエディタが開きます。ゲームとエディタは別々に起動できます。

## 配布用ゲームファイルの書き出し

エディタ上部の「配布用に書き出す」から、ゲーム本体・シナリオ・素材をまとめたZIPを作成できます。書き出し前にプロジェクト検査を行い、未保存の変更がある場合は保存を促します。生成したZIPはプロジェクト直下の `Games/` に保存され、フォルダがない場合は自動作成されます。同じタイトルで再度書き出すと、既存の配布ZIPを更新します。保存先のフルパスはエディタに表示されます。

配布ZIPにはシナリオエディタ、エディタ起動ファイル、`Games/` フォルダを含めません。`debug_mode.json` は配布物内だけ `enabled: false` にします。編集中プロジェクトのデバッグ設定やシナリオ・素材は変更しません。

配布ZIPを展開した後は `start.bat` からゲームを起動します。現行版はローカルサーバーを使うため、起動するPCに Python 3 が必要です。

## シナリオファイル

シナリオは専用テキスト形式 **G8S（8 Script）** で管理します。

- `data/opening.g8s`：最初に提示する通常ストーリー
- `data/scenarios/normal.g8s`：すべてのループで使う共通の通常シナリオ1本
- `data/scenarios/anomaly-01.g8s` など：異変シナリオ8本。どのループにも抽選されます
- `data/ending.g8s`：8回連続正解後のストーリー
- `data/scenario-index.json`：共通通常シナリオと異変シナリオ一覧
- `data/game.json`：タイトル、ループ回数、シナリオの参照先

ゲーム本体は `.g8s` を直接読み込みます。JSONへの変換作業は不要です。JSONはゲーム設定・素材一覧・シナリオ一覧などの管理に使用します。

## G8Sリファレンス

### 基本形

```text
タイトル：青いヘアピンがない
ID：anomaly_01
異変：あり

背景：clubroom
立ち絵：heroine（表情=no_hairpin、位置=中央）

地の文：
  放課後の部室には、窓から夕日が差し込んでいる。

澪：
  待った？ 日誌を書いていたら、少し遅くなっちゃった。

終了
```

### ヘッダー

| 書式 | 必須 | 仕様 |
|---|---|---|
| `タイトル：名前` | 任意 | シナリオの表示名。省略時はIDを使用。 |
| `ID：名前` | 必須 | シナリオID。空欄不可。 |
| `異変：あり` / `異変：なし` | 異変探し用は必須 | 通常シナリオは「なし」、異変シナリオは「あり」。オープニング・エンディングでは省略可能。 |

ヘッダーは最初のコマンドより前に記述します。

### コマンド

| 書式 | 動作・指定値 |
|---|---|
| `背景：clubroom` | 背景を切り替える。`manifest.json` の `assets.backgrounds` に登録したキーを指定。 |
| `立ち絵：heroine` | キャラクターを表示。表情の初期値は `default`、位置の初期値は `中央`。 |
| `立ち絵：heroine（表情=smile、位置=左）` | キャラクターID・表情キー・表示位置を指定。表情キーは `assets.characters` 内のキー。 |
| `立ち絵を隠す：heroine` | 指定したキャラクターだけを非表示にする。 |
| `立ち絵を隠す：全員` / `立ち絵を隠す：` | 表示中の立ち絵をすべて非表示にする。 |
| `待機：500ms` | 指定時間だけ再生を停止。単位は `ms` / `ミリ秒` / `秒`。単位省略時はミリ秒。小数も指定可能。 |
| `効果音再生：click` | `manifest.json` の `assets.audio` に登録した音声キーを指定し、効果音を1回再生。 |
| `BGM再生：main_theme` | 指定したBGMをループ再生。別のBGMを再生すると切り替わる。 |
| `BGMフェードアウト：3秒` | 指定時間をかけてBGMの音量を下げ、完了後に停止。倍速再生時は時間も短縮。単位は `ms` / `ミリ秒` / `秒`。単位省略時はミリ秒。 |
| `BGM停止` | 再生中のBGMを即時停止。 |
| `トランジション：切り替え（色=黒、方向=右から左、閉じる時間=0.5秒、待機=1秒、開く時間=0.5秒）` | 黒い幕で覆う → 暗転を保持 → 幕を開く、を1コマンドで実行。 |
| `トランジション：閉じる（色=黒、方向=右から左、時間=0.8秒）` | 黒い幕で画面を覆う。旧仕様も引き続き使用可能。 |
| `トランジション：開く（色=黒、方向=左から右、時間=0.8秒）` | 黒い幕を開く。旧仕様も引き続き使用可能。 |
| `地の文：` | 話者名を表示しない文章ページ。本文を次の行から記述。 |
| `澪：` | 話者名「澪」のセリフページ。任意の話者名を指定可能。 |
| `終了` | シナリオ終端。省略時はファイル末尾に自動追加。明示を推奨。 |

### シーントランジション

閉じる・暗転保持・開くを一度に実行する場合は、`切り替え` を使用します。

```text
トランジション：切り替え（色=黒、方向=右から左、閉じる時間=0.5秒、待機=1秒、開く時間=0.5秒）
```

`切り替え` は「黒い幕で覆う → 指定時間だけ黒画面を維持 → 黒い幕を開く」の順に実行します。方向は閉じる動作と開く動作の両方に適用されます。閉じる時間・待機時間・開く時間はそれぞれ独立して指定できます。

| 項目 | 指定値 | 既定値 |
|---|---|---|
| 色 | `黒` | 黒 |
| 方向 | `右から左` / `左から右` | 右から左 |
| 閉じる時間 | 0～60000ms。小数秒も指定可能 | 600ms |
| 待機 | 0～60000ms。小数秒も指定可能 | 0ms |
| 開く時間 | 0～60000ms。小数秒も指定可能 | 600ms |
| 時間 | `切り替え` の閉じる時間と開く時間の両方に適用 | 600ms |
| イージング | `linear` / `ease` / `ease-in` / `ease-out` / `ease-in-out` | linear |

`切り替え` は一括実行用の新仕様です。従来の `トランジション：閉じる` と `トランジション：開く` も引き続き有効です。黒画面の間に背景・立ち絵を変更したい場合は、従来の2コマンド方式を使用してください。

### 文章ブロック

```text
話者名：
  1行目のセリフ
  2行目のセリフ

地の文：
  1段落目。

  2段落目。
```

| ルール | 仕様 |
|---|---|
| 見出し行 | 左端から記述。例：`澪：`、`地の文：` |
| 本文 | 次の行から字下げ。半角スペース2個を推奨。 |
| 複数行 | 字下げされた行は同じ文章ページに連結。 |
| 空行 | 本文ブロック内では段落区切り。 |
| ブロック終端 | 次のコマンドまたは話者名を左端から記述。 |
| 本文の開始位置 | `澪：こんにちは` のように見出し行へ本文を続けず、必ず次の字下げ行から書く。 |

### 値・書式

| 項目 | 指定できる値 | 例 |
|---|---|---|
| 位置 | `中央` / `左` / `右` | `位置=中央` |
| 表情 | キャラクターごとに `manifest.json` へ登録したキー | `表情=smile` |
| 待機時間 | 数値。小数可。単位なし・`ms`・`ミリ秒` はミリ秒、`秒` は秒 | `待機：0.5秒` |
| トランジション時間 | 数値。小数可。単位なし・`ms`・`ミリ秒` はミリ秒、`秒` は秒。0～60000ms | `時間=0.35秒` |
| トランジション方向 | `右から左` / `左から右`。幕が画面を横切る向き | `方向=右から左` |
| イージング | `linear` / `ease` / `ease-in` / `ease-out` / `ease-in-out` | `イージング=ease-in-out` |
| 項目区切り | `：` または `:` | `背景:clubroom` |
| オプション区切り | `=` で値を指定。複数指定は `、` または `,` で区切る | `表情=smile、位置=中央` |
| コメント | 本文ブロック外で、行頭を `#` で始める | `# 部室の背景` |

背景キー・キャラクターID・表情キーは `manifest.json` の登録名と一致させます。大文字・小文字も区別されます。画像パスが `null` の場合は、manifestのプレースホルダー色で表示されます。

### 実行仕様と制約

- コマンドは上から順に実行されます。
- セリフ・地の文が連続する場合、会話ウィンドウは表示されたまま文章を更新します。背景・立ち絵・立ち絵非表示・待機・トランジションなどシーンを変更するコマンドを実行すると会話ウィンドウはいったん非表示になり、次のセリフまたは地の文で再表示されます。効果音・BGMのコマンドでは閉じません。シナリオ終端では非表示になります。
- 背景は次の背景指定まで維持されます。
- 立ち絵は別キャラクターを追加表示できます。表示中のキャラクターを消すには `立ち絵を隠す` を使います。
- `終了` の後に内容を置くことはできません。省略した場合は自動補完されます。
- `待機` は本編の通常再生時に適用されます。エディタのページ送りプレビューでは待機しません。
- `効果音再生` は指定した音声を1回再生し、再生完了を待たずに次のコマンドへ進みます。ゲーム内オプションのSE音量設定が適用されます。
- ゲーム中の歯車アイコンからBGM・SEの音量を個別に10段階で設定できます。設定はブラウザに保存され、0は消音です。
- `BGM再生` は指定した音声をループ再生します。同じキーを再指定しても再スタートせず、別のキーを指定すると切り替わります。`BGMフェードアウト` は指定時間をかけて音量を下げ、完了後に停止します。倍速再生時はフェード時間も再生速度に合わせて短縮します。`BGM停止` は即時停止です。BGM音量はSE音量と独立して設定できます。
- 効果音・BGMのコマンドは会話ウィンドウを閉じません。ページ送りプレビューでは音声を再生せず、ゲームプレイプレビューと本編で再生します。
- `トランジション：切り替え` は閉じる・暗転保持・開くを連続実行します。従来の `閉じる` / `開く` は、黒画面の間に背景・立ち絵などを変更する用途で引き続き利用できます。
- `時間` は `800ms` または `0.8秒` の形式で指定でき、小数秒にも対応します。0～60000msの範囲です。既定値は600msです。
- `イージング` は時間内の速度変化を指定します。既定値 `linear` は一定速度です。
- エディタのページ送りプレビューは選択中ページまでのコマンドを適用し、トランジション後の画面状態を表示します。アニメーションそのものは本編で再生されます。
- `タイトル`・`ID`・`異変`・`種類`・`背景`・`立ち絵`・`立ち絵を隠す`・`待機`・`トランジション`・`効果音再生`・`BGM再生`・`BGM停止`・`BGMフェードアウト`・`地の文` は予約済みの項目名です。`種類` は現在値を読み取らないため使用しないでください。
- 現在、選択肢、条件分岐、変数、黒以外のトランジションには対応していません。

編集画面の「G8Sリファレンス」には、このプロジェクトのmanifestから取得した背景キー・キャラクターID・表情キー・音声キーも表示されます。

## 異変の抽選

`data/scenario-index.json` で通常シナリオ1本と異変シナリオをまとめて管理します。

```json
{
  "selection": {
    "anomalyChance": 0.6,
    "maxConsecutiveNormal": 3,
    "rememberFoundAnomalies": true,
    "repeatAfterAllFound": true
  },
  "normal": "data/scenarios/normal.g8s",
  "anomalies": [
    "data/scenarios/anomaly-01.g8s",
    "data/scenarios/anomaly-02.g8s"
  ]
}
```

通常シナリオは毎回同じファイルを再生します。異変シナリオは一覧全体から抽選し、チェックポイントごとの紐付けはありません。初期状態では異変シナリオが8本登録されています。

- `anomalyChance`：異変が出現する基本確率。初期値は約60%。
- `maxConsecutiveNormal`：異変なしがこの回数続いた次の遭遇では、異変を必ず出します。
- `rememberFoundAnomalies`：正しく見つけた異変をブラウザに記録し、再出現を避けます。
- `repeatAfterAllFound`：登録された異変をすべて発見したら、既知の異変も再抽選対象に戻します。

## プレイ中の倍速

ゲーム画面右上の「倍速」ボタンで通常速度（1x）と倍速（2x）を切り替えます。設定はプレイ中にいつでも変更でき、G8Sの「待機」、トランジションの閉じる時間・暗転保持時間・開く時間、判定後の待ち時間、スタッフロールとエンディングへのフェードにも反映されます。

ボタンの表示文言はデータ編集タブの「ゲーム中の操作・表示テキスト」で変更できます。ゲーム本体のプレイ画面にある「最初から」ボタンは廃止し、タイトル画面からゲームを開始する導線に統一しています。

## プレイ中の挙動

- 異変あり：頬を叩くとその場でシナリオを中断して判定します。
- 異変なし：ボタンを押さずに最後まで再生すれば正解です。
- 異変の見逃し：シナリオを最後まで再生してから1回目へ戻ります。
- 8回連続正解でエンディングです。
- エンディングの「タイトルへ」でタイトル画面に戻ります。

## デバッグ表示

`debug_mode.json` の `enabled` を `true` / `false` にして切り替えます。ONの場合、異変探し中に異変の有無を表示します。

## 素材

`manifest.json` の `assets` に画像・音声のパスを指定します。画像が未設定の場合は単色矩形で表示します。シナリオで使用する背景・キャラクター・表情はmanifestに登録してください。

## シナリオエディタ

`start_editor.bat` をダブルクリックします。エディタは **2カラム** です。左側にG8S本文、右側にプレビューを表示します。シナリオの内容はテキストだけで編集でき、JSONやプログラムを操作する必要はありません。

上部のシナリオ選択から opening・ending・共通通常シナリオ1本・異変シナリオ一覧を切り替えます。右側のプレビューはゲーム本編の `index.html` をiframeで読み込みます。描画DOM・CSS・`SceneRenderer`・`CharacterRenderer`・`DialogueBox`・`ScenarioPlayer` をゲーム本編と完全に共用し、エディタ独自のプレビュー描画は行いません。プレビューの内部画面サイズは実行端末の `screen.width × screen.height` に合わせ、エディタ内ではその画面を縮小表示します。そのため画面比率に加えて、`vw` / `vh` や画面幅によるCSS切り替えも本編と同じ条件で描画されます。保存はボタンまたは `Ctrl+S`。入力中はプレビューが更新されます。「＋背景」「＋立ち絵」「＋トランジション」「＋効果音」「＋BGM」「＋BGMフェードアウト」「＋BGM停止」「＋地の文」「＋セリフ」で書式を挿入できます。「検査」ではプロジェクト全体のシナリオと素材参照を確認できます。「異変を追加」は現在の通常または異変シナリオを複製し、異変シナリオ一覧に登録します。

## OneDrive環境でのファイル操作

ブラウザからローカルファイルを直接操作せず、Pythonサーバーがこのプロジェクトフォルダ内だけを読み書きします。OneDrive全体の走査や同期状態の強制変更は行いません。

- 自動保存や常時ファイル監視は行いません。保存ボタンまたは `Ctrl+S` を押したときだけ書き込みます。
- 読み込み・保存は短い間隔で再試行します。
- 同じフォルダ内の一時ファイルへ書き込み、フラッシュ後に置き換えます。
- 保存前の内容は `.editor-backups` に退避します。
- エディタを開いた後に外部変更されたファイルは、ハッシュで検出して上書きを中止します。
- オンラインのみのファイルが読めない場合は、エクスプローラーで対象ファイルのダウンロードが完了してから再試行してください。

エディタサーバーは `127.0.0.1` のみで待ち受けます。


## v0.19 プレビューのページ数

プレビューのページ送り対象は「セリフ」と「地の文」だけです。背景変更・立ち絵変更・立ち絵非表示・待機・音声・終了はページ数に含めず、選択中の文章を表示する前にゲーム本編と同じ `ScenarioPlayer` で画面状態を反映します。ページ確認では音声を再生しません。


## シナリオエディタの編集支援

- シナリオ内検索：本文・話者・コマンド・素材キーを検索し、結果から該当行とプレビューへ移動できます。`Ctrl+F` で検索欄にフォーカスし、`Enter` / `Shift+Enter` で結果を移動できます。
- 素材ピッカー：manifest.jsonに登録された背景・キャラクター・表情を選び、G8Sコマンドとして挿入できます。
- 全ページレイアウト検査：端末画面寸法を使った本編プレビューで全テキストページを描画し、会話ウィンドウの画面外はみ出しを検査します。
- エラー箇所へのジャンプ：構文エラー・素材参照エラー・プロジェクト検査結果を選択すると、該当ファイルと行へ移動できます。

いずれも既存のG8Sテキストを直接編集する仕組みを維持し、読み込み・検査時にシナリオデータを自動変換しません。


## データ編集タブ

データ編集タブでは、ゲームタイトルと素材設定をフォームから管理します。素材設定は「背景」「キャラクター」「音声」に分かれ、キー名・代替表示色（背景／キャラクター）・表情ごとの画像を編集できます。画像・音声の割り当ては素材ブラウザから行い、`assets/backgrounds/`・`assets/characters/`・`assets/audio/` のフォルダをたどって実ファイルを選択できます。画像はサムネイル、音声は選択前に試聴できます。キャラクターごとに立ち絵の拡大率（1～500%）とX/Y位置補正（-2000～2000px）を設定でき、同じキャラクターの全表情に共通のデフォルト値として適用されます。追加・名前変更・削除は一覧上で行い、内部の `manifest.json` は保存形式として扱います。保存時は既存ファイルのバックアップと外部変更検出を使用します。


## ゲーム画面プレビュー

プレビュー領域は「ページ確認」と「ゲームプレイ」を切り替えられます。

- **ページ確認**：選択したシナリオの文章ページを1ページずつ表示します。編集中の未保存テキストも反映され、全ページレイアウト検査を利用できます。
- **ゲームプレイ**：ゲーム本編をエディタ内の画面で起動します。タイトル画面から開始し、オープニング・異変探し・判定・エンディングまで通常のゲームと同じ操作でプレイできます。`start.bat` を別に起動する必要はありません。
- ゲームプレイはプロジェクトに保存済みのデータを読み込みます。未保存のシナリオ・タイトル・素材設定がある場合は、保存するまでモードを切り替えません。
- 「ゲームを再起動」でタイトル画面からやり直せます。「ページ確認」に戻ると、現在エディタで選択しているページのプレビューに戻ります。
- ゲーム本編と同じ `1920×1080（16:9）` の固定デザインキャンバスで描画します。エディタ内ではキャンバス全体を比率を維持して縮小表示し、立ち絵や会話ウィンドウの位置・寸法はプレビュー枠の大きさに左右されません。


## タイトル画面・エンディング・スタッフロール

データ編集タブの「ゲームタイトル」から、それぞれ独立して設定できます。

- ゲーム名：プロジェクトの識別名。既存の `title` を維持します。
- タイトル画面の表示名：`titleScreenTitle`。未設定時はゲーム名を表示します。
- エンディング画面の表示名：`endingScreenTitle`。未設定時は従来どおりエンディングシナリオのタイトルを使用します。
- スタッフロール：`credits` 配列。エディタでは1行につき「役割：名前」で入力します。
- スタッフロールの背景：`staffRollBackground`。素材・表示設定に登録した背景キーから選択します。未設定時は黒背景です。

エンディングシナリオの再生後、スタッフロール専用画面でクレジットが下から上へ流れ、最後まで表示するとエンディング画面へ移ります。`credits` が空ならスタッフロール画面を省略します。設定は `data/game.json` に保存され、既存の `title`、進行設定、シナリオ参照は保持されます。


## エンディング画面

データ編集タブの「エンディング画面の背景」から、素材・表示設定に登録した背景を選択できます。スタッフロールの背景とは独立しており、スタッフロール終了後はクロスフェードでエンディング画面へ切り替わります。未設定の場合は暗い単色背景になります。


### ゲーム中の表示テキスト

データ編集タブの「ゲーム中の操作・表示テキスト」から、開始・会話送り・頬を叩く・タイトルへ・効果音ON/OFF・倍速OFF/ONの各表示、会話ヒント、進行状況、スタッフロール見出し、デバッグ表示、読み込みエラー表示を編集できます。設定は `data/game.json` の `uiText` に保存されます。進行状況の表示形式では `{current}` と `{total}` を使用できます。未設定のキーは既定の表示文言を使用します。

## 画面レイアウトの基準

ゲーム画面は **1920×1080（16:9）** の固定デザインキャンバス上で描画し、表示領域に合わせて縦横比を維持したまま一括拡大・縮小します。16:9以外の画面ではキャンバス全体が収まるように黒帯が入ります。立ち絵、会話ウィンドウ、ボタン、背景、スタッフロールは同じキャンバスを基準に配置されるため、プレビュー枠やモニターのサイズによって個別の寸法・位置関係が変化しません。

キャラクター別のX/Y補正値は、この1920×1080キャンバス上のデザインpxです。画面全体の拡大・縮小に合わせて補正値も一緒に拡大・縮小されます。
